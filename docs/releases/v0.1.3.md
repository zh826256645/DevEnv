# DevEnv v0.1.3 Private Preview

DevEnv `v0.1.3`（Build `4`）是面向受邀测试者的私有预览版本，不属于稳定正式版。

## 主要变更

- 新增工作区：无需绑定目录即可创建、重命名和切换，在项目与运行页签管理各自内容；本机环境、总览和状态栏保持全局。
- 项目记录拥有独立身份与可编辑名称，同一目录可加入同一或不同工作区；自动发现按工作区去重和处理忽略。
- 运行配置可独立存在，也可关联同工作区项目。工作目录支持绝对路径、项目相对路径（允许 `../`）或留空；留空时使用关联项目目录，否则使用启动时的当前用户目录。
- 移除 Project Trust 确认。运行仍须由用户明确触发，扫描不会自动执行命令；每次执行冻结命令和目录，保留目录有效性、禁用状态、活动执行冲突与进程所有权检查。
- 删除项目保留配置和当前运行，失效关联需显式解除或重新关联。解除关联保留原执行目录，重新添加相同目录不会恢复旧关联。
- 删除配置或工作区前确认影响并安全停止相关运行；停止或保存失败保留记录，不删除磁盘项目目录及文件。
- 工作区运行页按当前筛选结果批量操作；状态栏汇总全部工作区，并显示工作区名称与全局操作范围。独立运行的失败、进程归属证据不足和端口暴露仍进入总览。
- 修复添加父目录后旧配置丢失原目录上下文，以及同目录跨工作区运行时总览遗漏要求风险的问题。

## 升级与数据

旧项目与运行配置迁入默认工作区，保留命令原文、工作目录含义、来源和启用状态，旧 Project Trust 数据不再保留。项目记录文档升级至 schema 7；升级前建议备份本机 App 数据，不应假设旧版能够读取升级后的记录。

运行会话和终端输出只存在于当前 App 进程，升级时不会迁移。完全退出旧版 DevEnv 后再替换 App。

## 系统要求与安装

- macOS 15.0 或更高版本，Apple Silicon `arm64`；不包含 Intel 构建。
- Bundle ID：`io.github.zh826256645.DevEnv`。
- 下载 `DevEnv-0.1.3-arm64.dmg` 和对应 `.sha256` 文件，先验证摘要。
- 打开 DMG，将 App 拖入 `Applications`，再启动新版。

## 签名与首次打开限制

App 使用 ad-hoc 签名，仅用于 Bundle 完整性校验；没有 Developer ID 签名、Apple 公证或 Stapling。首次打开如被 Gatekeeper 阻止，请先尝试打开，再通过“系统设置 → 隐私与安全性”确认打开。不要全局关闭 Gatekeeper，也不要递归移除隔离属性。

## Known Limitations

- 不提供稳定性或长期兼容性承诺，不提供自动更新，请从 GitHub Prerelease 手动下载。
- 不支持跨工作区移动或复制项目与配置，也不支持跨工作区项目关联。
- 本地服务仅观察 TCP 监听，不等同于健康检查；证据不足时保留未知归属。
- 停止操作受进程归属与系统权限约束；环境扫描不会自动安装或启动依赖。
- DevEnv 不启用 App Sandbox，运行命令以当前用户权限执行；启动前应核对命令和工作目录。

## SHA-256 校验

将两个文件放在同一目录后执行：

```bash
shasum -a 256 -c DevEnv-0.1.3-arm64.dmg.sha256
```

预期显示 `DevEnv-0.1.3-arm64.dmg: OK`；校验失败时不要安装，应重新从该 Release 下载。
