# DevEnv v0.1.1 Private Preview

DevEnv `v0.1.1`（Build `2`）是面向受邀测试者的私有预览修复版本，不属于稳定正式版。

本版本采用所有者授权的本地发布通道：在 Apple Silicon Mac 上对发布提交执行完整测试、Release 构建和最终 DMG 校验，再上传 GitHub Draft Prerelease；不把因账单限制未执行的 Hosted CI 标记为通过。

## 主要变更

- 修复 Homebrew 服务发现因强制限制 Formula 来源而漏显示的问题，保留禁止自动更新。
- 改进项目运行子进程退出确认与回收，不再将提前到达的终端通知直接视为进程退出。
- 停止失败后继续只读复查，确认归属进程全部退出时自动完成状态收尾。

## 系统要求与安装

- macOS 15.0 或更高版本，Apple Silicon `arm64`；不包含 Intel 构建。
- Bundle ID：`io.github.zh826256645.DevEnv`。
- 下载 `DevEnv-0.1.1-arm64.dmg` 和 `DevEnv-0.1.1-arm64.dmg.sha256`，先验证摘要。
- 完全退出旧版 DevEnv 后打开 DMG，将 App 拖入 `Applications`，再启动新版。运行会话不跨 App 进程迁移；项目记录、运行配置和信任记录保持现有兼容语义。

## 签名与首次打开限制

App 使用 ad-hoc 签名，仅用于 Bundle 完整性校验；没有 Developer ID 签名、Apple 公证或 Stapling。首次打开如被 Gatekeeper 阻止，请先尝试打开，再通过“系统设置 → 隐私与安全性”确认打开。

不要全局关闭 Gatekeeper，也不要递归移除隔离属性。

## Known Limitations

- Private Preview 不提供稳定性或长期兼容性承诺，不提供自动更新；请从 GitHub Prerelease 手动下载。
- 停止操作仍受进程所有权与系统权限约束；无法可靠确认归属或退出时仍可能显示停止失败。本版本不保证任何进程均可强制终止，也不提供“结束跟踪”来伪装停止成功。
- 旧版已经卡住的内存会话不会因安装新版而直接修复；本次修复需在新版运行中生效。
- DevEnv 不启用 App Sandbox，项目命令以当前用户权限执行，仅应信任已核对的项目。
- 本地服务只观察 TCP 监听，不等同于服务健康；环境扫描不会自动安装或启动依赖。

## SHA-256 校验

将两个文件放在同一目录后执行：

```bash
shasum -a 256 -c DevEnv-0.1.1-arm64.dmg.sha256
```

预期显示 `DevEnv-0.1.1-arm64.dmg: OK`。校验失败时不要安装，应重新从该 Release 下载。
