# DevEnv v0.2.3 Private Preview

DevEnv `v0.2.3`（Build `9`）是面向早期测试者的预览版本，不属于稳定正式版。

## 主要变更

- 修复 macOS 27 自动隐藏菜单图标导致菜单栏运行状态点、运行配置 Logo 和操作图标不显示的问题。
- 显式显示主菜单及子菜单中已有图标，覆盖未启动、运行中和终端就绪状态。
- 继续复用现有 Logo 资源；较早 macOS 保持原有显示行为。
- 保留 v0.2.2 的批量停止、关闭直接执行体验；删除与存储恢复确认继续保留。

## 升级与数据

从 v0.2.2 升级继续沿用 schema 8。本次不改变项目与运行配置的持久化格式及已有迁移逻辑。升级前建议备份本机 App 数据。

运行会话和终端输出只存在于当前 App 进程，升级时不会迁移。请先结束需要保留的工作，完全退出旧版 DevEnv 后再替换 App；重新打开不会自动执行配置命令。

## 系统要求与安装

- macOS 15.0 或更高版本，Apple Silicon `arm64`；不包含 Intel 构建。
- Bundle ID：`io.github.zh826256645.DevEnv`。
- 本次按所有者选择使用 Xcode `27.0 (27A266a)` 本地验证和构建，GitHub Actions 的固定工具链不变。
- 下载 `DevEnv-0.2.3-arm64.dmg` 和对应 `.sha256` 文件，先验证摘要。
- 打开 DMG，将 App 拖入 `Applications`，再启动新版。

## 签名与首次打开限制

App 使用 ad-hoc 签名，仅用于 Bundle 完整性校验；没有 Developer ID 签名、Apple 公证或 Stapling。首次打开如被 Gatekeeper 阻止，请先尝试打开，再通过“系统设置 → 隐私与安全性”确认打开。不要全局关闭 Gatekeeper，也不要递归移除隔离属性。

## Known Limitations

- 不提供稳定性或长期兼容性承诺，不提供自动更新。
- 持续终端支持 zsh、bash、fish 和 sh；其他 Shell 会明确提示不支持。自定义 Shell 初始化或提示符插件可能影响就绪通知，未收到可靠通知时不会继续发送配置命令。
- 普通停止只发送 Ctrl+C，不强制杀死命令；无响应时可显式关闭终端。终端关闭和 App 退出受进程归属核验与系统权限约束。
- 手动命令不会改写运行配置；配置退出码及失败提示只跟踪通过启动或重启执行的配置命令。终端就绪不代表后台任务或监听端口已经结束。
- 本地服务仅观察 TCP 监听，不等同于健康检查；证据不足时保留未知归属。
- DevEnv 不启用 App Sandbox，命令以当前用户权限执行；环境扫描不会自动安装或启动项目依赖。

## SHA-256 校验

将两个文件放在同一目录后执行：

```bash
shasum -a 256 -c DevEnv-0.2.3-arm64.dmg.sha256
```

预期显示 `DevEnv-0.2.3-arm64.dmg: OK`；校验失败时不要安装。

## 构建验证

本次采用仓库所有者批准的 Xcode `27.0 (27A266a)` 本地发布通道。正式安装包从 `master` 精确合并提交重新构建；四组发布契约测试、完整 XCTest、arm64 Release 构建及安装包校验结果随 GitHub Release 发布记录提供。未执行或失败的 Hosted CI 不记为通过。
