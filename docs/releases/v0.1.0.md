# DevEnv v0.1.0 Private Preview

DevEnv `v0.1.0`（Build `1`）是首个 **Private Preview（私有预览版）**，面向拥有 Private GitHub 仓库访问权限的受邀测试者。本版本用于验证 macOS 本地项目运行工作台的核心流程，不属于稳定正式版。

## 系统要求与发布产物

- 最低系统：macOS 15.0
- 处理器架构：Apple Silicon `arm64`
- 不支持：Intel `x86_64`
- 安装包：`DevEnv-0.1.0-arm64.dmg`
- 校验文件：`DevEnv-0.1.0-arm64.dmg.sha256`
- Bundle ID：`io.github.zh826256645.DevEnv`

## 签名、公证与首次打开限制

本版本对完整 App Bundle 执行 **ad-hoc 签名**，仅用于校验 Bundle 内部完整性；它没有使用 Developer ID Application 证书，也没有经过 Apple 公证或 Stapling。因此，macOS Gatekeeper 可能阻止首次打开。

如果首次打开被阻止：

1. 先尝试从“应用程序”文件夹打开 DevEnv，让系统显示阻止提示；
2. 打开“系统设置 → 隐私与安全性”；
3. 在安全性区域确认打开 DevEnv，并再次核对系统提示。

请勿为了安装本版本而全局关闭 Gatekeeper，也不要递归移除下载文件的隔离属性。

## 安装方式

1. 从 Private GitHub Prerelease 下载 DMG 与同名 `.sha256` 文件；
2. 按下方步骤校验 SHA-256；
3. 打开 `DevEnv-0.1.0-arm64.dmg`；
4. 将 `DevEnv.app` 拖入 DMG 中的 `Applications` 链接；
5. 从“应用程序”文件夹启动 DevEnv；如被 Gatekeeper 阻止，按上一节使用系统界面确认打开。

本版本不提供自动更新。后续版本需要从 Private GitHub Release 手动下载并安装。

## 主要变更

- 提供原生 macOS 项目运行工作台，可保存、启用、停用和管理多个 Project Run Configuration；
- 支持在明确触发和首次信任确认后启动、停止、重启及批量管理 Project Run Session；
- 集成交互式终端输出、运行状态、退出结果、持续时间、内存占用、Git 仓库状态和可可靠归属的 TCP 监听端口；
- 支持发现 Project Root，并静态分析 Node.js、Python、Go、Java、Rust、Ruby、Lua、包管理器、数据库与 Compose 等 Project Requirements；
- 提供 Machine Environment 扫描，展示 macOS、PATH、Homebrew、Runtime、数据库安装、本地监听服务、Git、Terminal Application 与 Shell 状态；
- 支持在展示具体命令并取得确认后管理当前用户可管理的 Homebrew Service；
- 关闭主窗口后保留状态栏入口和当前进程内的运行会话，完全退出时清理仍活动的会话；
- 保留 Project Record、运行配置和 Project Trust，并兼容 schema 1–4 的现有迁移语义。

## Known Limitations

- 本版本是受邀测试范围内的 Private Preview，不提供稳定性、长期数据格式或版本兼容性承诺；
- 仅支持 macOS 15.0 及 Apple Silicon `arm64`，不包含 Intel 构建；
- App 未使用 Developer ID 签名且未经 Apple 公证，首次打开可能需要在“系统设置 → 隐私与安全性”中人工确认；
- 不提供自动更新、公开下载渠道或正式分发信任链；
- DevEnv 当前不启用 App Sandbox。项目命令以当前用户权限交给 Default Login Shell 执行，只应为已核对且可信的 Project Root 保存信任；
- Machine Environment 与 Project Requirements 结果是当前用户可见范围内的本地证据，不保证项目一定能够运行；静态或不可读取的声明可能显示“无法判断”；
- Local Service 与端口观察只覆盖能够确认的 TCP Listener Binding，不覆盖仅使用 Unix Socket 的服务，也不表示连接、鉴权、Schema 或服务健康；
- Environment Scan 不会自动安装、修复或启动依赖，Project Requirements 分析也不会执行项目代码或动态清单表达式。

## SHA-256 校验

将 DMG 和 `.sha256` 文件放在同一目录，在终端进入该目录后运行：

```bash
shasum -a 256 -c DevEnv-0.1.0-arm64.dmg.sha256
```

输出包含以下内容时表示下载文件与发布摘要一致：

```text
DevEnv-0.1.0-arm64.dmg: OK
```

如果校验失败，请删除文件并重新从该 Private GitHub Prerelease 下载；不要继续安装摘要不匹配的 DMG。
