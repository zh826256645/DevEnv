# DevEnv v0.2.1 Private Preview

DevEnv `v0.2.1`（Build `7`）是面向早期测试者的预览版本，不属于稳定正式版。

## 主要变更

- 运行配置支持关联网页，可从运行详情、配置列表和更多操作中打开默认浏览器。
- 支持运行配置启动成功后按设定延时自动打开关联网页。
- 修复应用刚启动后首次打开运行配置编辑窗口时，命令字段暂时为空的问题。
- 编辑器增加滚动布局，运行配置表单在较小窗口中也能完整访问。

## 升级与数据

从 `v0.2.0` 升级继续使用 schema 7 的项目与运行配置记录，不新增数据迁移。升级前建议备份本机 App 数据。

运行会话和终端输出只存在于当前 App 进程，升级时不会迁移。请先结束需要保留的工作，完全退出旧版 DevEnv 后再替换 App；重新打开不会自动执行配置命令。

## 系统要求与安装

- macOS 15.0 或更高版本，Apple Silicon `arm64`；不包含 Intel 构建。
- Bundle ID：`io.github.zh826256645.DevEnv`。
- 下载 `DevEnv-0.2.1-arm64.dmg` 和对应 `.sha256` 文件，先验证摘要。
- 打开 DMG，将 App 拖入 `Applications`，再启动新版。

## 签名与首次打开限制

App 使用 ad-hoc 签名，仅用于 Bundle 完整性校验；没有 Developer ID 签名、Apple 公证或 Stapling。首次打开如被 Gatekeeper 阻止，请先尝试打开，再通过“系统设置 → 隐私与安全性”确认打开。不要全局关闭 Gatekeeper，也不要递归移除隔离属性。

## Known Limitations

- 不提供稳定性或长期兼容性承诺，不提供自动更新，请从 GitHub Prerelease 手动下载。
- 持续终端支持 zsh、bash、fish 和 sh；其他 Shell 会明确提示不支持。自定义 Shell 初始化或提示符插件可能影响就绪通知，未收到可靠通知时不会继续发送配置命令。
- 普通停止只发送 Ctrl+C，不强制杀死命令；无响应时可显式关闭终端。终端关闭和 App 退出受进程归属核验与系统权限约束。
- 手动命令不会改写运行配置；配置退出码及失败提示只跟踪通过启动或重启执行的配置命令。终端就绪不代表后台任务或监听端口已经结束。
- 本地服务仅观察 TCP 监听，不等同于健康检查；证据不足时保留未知归属。
- DevEnv 不启用 App Sandbox，命令以当前用户权限执行；环境扫描不会自动安装或启动项目依赖。

## SHA-256 校验

将两个文件放在同一目录后执行：

```bash
shasum -a 256 -c DevEnv-0.2.1-arm64.dmg.sha256
```

预期显示 `DevEnv-0.2.1-arm64.dmg: OK`；校验失败时不要安装，应重新从该 Release 下载。
