# DevEnv v0.1.4 Private Preview

DevEnv `v0.1.4`（Build `5`）是面向早期测试者的预览版本，不属于稳定正式版。

## 主要变更

- 运行配置使用持续交互终端：命令结束或按 Ctrl+C 后可继续输入，共享当前目录、环境变量和输出历史。支持 zsh、bash、fish 和 sh，并优先使用本机已安装的 Nerd Font 显示提示符图标。
- 区分命令执行中与终端就绪。运行中点击停止发送 Ctrl+C 并保留终端，就绪时按钮改为关闭；重启等待 Shell 就绪后再执行配置命令，中断超时会提示失败。
- 运行页直接显示项目筛选、全部启动和全部暂停，缩小搜索框与控件，窄窗口也保持单行。当前范围内只剩就绪终端时切换为全部关闭；状态栏对全部工作区采用相同规则。
- 批量操作冻结触发时的目标，确认前开始新命令的终端不会被旧关闭请求关闭。切换页面、工作区或关闭主窗口保留会话，完全退出 App 才结束。
- 项目和运行配置可在工作区间移动，可选择携带有效关联内容；移动保留身份和当前会话，关联失效时明确提示，不修改磁盘目录。
- 统一项目与运行配置页面布局，窄窗口依次隐藏次要表格列，扩大详情页签点击区域；总览以运行会话为主，支持工作区筛选，并保留就绪会话的监听、内存与风险信息。

## 升级与数据

从 `v0.1.3` 升级继续使用 schema 7 的项目与运行配置记录，不新增数据迁移。更早版本的记录沿用既有迁移流程；升级前建议备份本机 App 数据。

运行会话和终端输出只存在于当前 App 进程，升级时不会迁移。请先结束需要保留的工作，完全退出旧版 DevEnv 后再替换 App；重新打开不会自动执行配置命令。

## 系统要求与安装

- macOS 15.0 或更高版本，Apple Silicon `arm64`；不包含 Intel 构建。
- Bundle ID：`io.github.zh826256645.DevEnv`。
- 下载 `DevEnv-0.1.4-arm64.dmg` 和对应 `.sha256` 文件，先验证摘要。
- 打开 DMG，将 App 拖入 `Applications`，再启动新版。

## 签名与首次打开限制

App 使用 ad-hoc 签名，仅用于 Bundle 完整性校验；没有 Developer ID 签名、Apple 公证或 Stapling。首次打开如被 Gatekeeper 阻止，请先尝试打开，再通过“系统设置 → 隐私与安全性”确认打开。不要全局关闭 Gatekeeper，也不要递归移除隔离属性。

## Known Limitations

- 不提供稳定性或长期兼容性承诺，不提供自动更新，请从 GitHub Prerelease 手动下载。
- 持续终端支持 zsh、bash、fish 和 sh；其他 Shell 会明确提示不支持。自定义 Shell 初始化或提示符插件可能影响就绪通知，未收到可靠通知时不会继续发送配置命令。
- 普通停止只发送 Ctrl+C，不强制杀死命令；无响应时可显式关闭终端。终端关闭和 App 退出受进程归属核验与系统权限约束。
- 手动命令不会改写运行配置；配置退出码及失败提示只跟踪通过启动或重启执行的配置命令。终端就绪不代表后台任务或监听端口已经结束。
- 本地服务仅观察 TCP 监听，不等同于健康检查；证据不足时保留未知归属。
- DevEnv 不启用 App Sandbox，命令以当前用户权限执行；环境扫描不会自动安装或启动项目依赖。

## SHA-256 校验

将两个文件放在同一目录后执行：

```bash
shasum -a 256 -c DevEnv-0.1.4-arm64.dmg.sha256
```

预期显示 `DevEnv-0.1.4-arm64.dmg: OK`；校验失败时不要安装，应重新从该 Release 下载。
