# DevEnv v0.1.2 Private Preview

DevEnv `v0.1.2`（Build `3`）是面向受邀测试者的私有预览版本，不属于稳定正式版。

## 主要变更

- 扩展 Node.js、Bun、Go、Rust、Java 监听服务的运行时与项目识别，分别展示项目名称和服务目录。
- 基于工作目录、项目清单及 Java 启动路径证据识别归属；证据不足或冲突时保留未知，不猜测项目。
- 修复微信、企业微信等原生 App 服务被误识别为项目的问题，恢复显示 App 名称。
- 避免用户主目录的项目清单和 Homebrew 自身 Git 目录导致服务归属误判。
- 移除折叠侧栏时重复出现的侧栏按钮，保留系统原生开关。

## 系统要求与安装

- macOS 15.0 或更高版本，Apple Silicon `arm64`；不包含 Intel 构建。
- Bundle ID：`io.github.zh826256645.DevEnv`。
- 下载 `DevEnv-0.1.2-arm64.dmg` 和对应 `.sha256` 文件，先验证摘要。
- 完全退出旧版 DevEnv 后打开 DMG，将 App 拖入 `Applications`，再启动新版。运行会话不跨 App 进程迁移；项目记录、运行配置和信任记录保持现有兼容语义。

## 签名与首次打开限制

App 使用 ad-hoc 签名，仅用于 Bundle 完整性校验；没有 Developer ID 签名、Apple 公证或 Stapling。首次打开如被 Gatekeeper 阻止，请先尝试打开，再通过“系统设置 → 隐私与安全性”确认打开。不要全局关闭 Gatekeeper，也不要递归移除隔离属性。

## Known Limitations

- 不提供稳定性或长期兼容性承诺，不提供自动更新，请从 GitHub Prerelease 手动下载。
- 本地服务仅观察 TCP 监听，不等同于健康检查；独立二进制、JAR 或多语言目录可能因证据不足而无法识别源码项目。
- 停止操作受进程归属与系统权限约束；环境扫描不会自动安装或启动依赖。
- DevEnv 不启用 App Sandbox，项目命令以当前用户权限执行，仅应信任已核对的项目。

## SHA-256 校验

将两个文件放在同一目录后执行：

```bash
shasum -a 256 -c DevEnv-0.1.2-arm64.dmg.sha256
```

预期显示 `DevEnv-0.1.2-arm64.dmg: OK`；校验失败时不要安装，应重新从该 Release 下载。
